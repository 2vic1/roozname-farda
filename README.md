# 📰 روزنامه فردا

**سامانه هشدار جنگ و پیش‌بینی بازارها** — داشبورد فارسی (RTL، تم تاریک) که ریسک ژئوپلیتیک را با چند سیگنال ترکیبی می‌سنجد و برای ۸ بازار مالی پیش‌بینی ۳۰ روزه با ۴ روش مختلف ارائه می‌دهد.

> خبرهای فردا را امروز بخوان.

---

## ✨ امکانات

### 🛡️ هشدار جنگ (War Risk)
- **شاخص ۰ تا ۱۰۰** از ترکیب چند سیگنال: پروازهای بمب‌افکن/سوخت‌رسان آمریکا، نوسان بازارها (BTC، نفت WTI/برنت، طلا، S&P)، شمارش اخبار منابع خارجی و…
- **فوز ۶۰/۴۰** سیگنال علمی + آسترو (تفاوت کم → سینرژی مثبت، تفاوت زیاد → جریمه)
- **ستاره‌شناسی جنگ**: نقشه آسمان امروز + ۴ تاریخ پرخطر پیشِ رو با درجه اطمینان
- **اخبار فقط از منابع خارجی** (رسانه‌های رسمی ایران ممنوع) + ترجمه فارسی هر خبر
- **تب‌های ستاره‌شناسی، تاروت و آب‌وهوا**

### 📈 پیش‌بینی بازار (تب بازار)
- **۸ بازار**: بیت‌کوین، اتریوم، انویدیا، S&P 500، نفت WTI، نفت برنت، طلا، نقره
- **۴ روش پیش‌بینی برای هر بازار**: تکنیکال، چرخه‌های بلندمدت، استرولوژی مالی، ترکیب همه
- **کندل‌استیک واقعی**: هر روزِ پیش‌بینی بدنه و سایه دارد (پیش رفت تا کجا / ریخت تا کجا) با رنگ روش متد
- **آزمون گذشته (دقت‌سنجی)**: بک‌تست روزانه هر متد روی داده واقعی + خطای درصدی
- **نقشه تولد هر بازار**: WTI = اولین قرارداد آتی NYMEX (۱۹۸۳)، برنت = IPE لندن (۱۹۸۸)، طلا = شوک نیکسون (۱۹۷۱)، نقره = قانون ضرب سکه (۱۹۶۵)…

### 🤖 ربات تلگرام
- `/start` `/check` `/report` + دکمه مینی‌اپ
- دستورات ادمین `/setkey` `/setbase` `/setmodel` برای ست کردن کلید AI از خود تلگرام
- کد مستقل در `telegram-app/` — اجرا با Bun روی هر سروری

## 🚀 اجرای محلی

```bash
# ۱) نصب وابستگی‌ها
bun install

# ۲) متغیرهای محیطی
cp .env.example .env   # و مقادیر را پر کن (حداقل DATABASE_URL)

# ۳) ساخت دیتابیس
bun run db:push

# ۴) اجرا
bun run dev            # http://localhost:3000
```

### متغیرهای محیطی

| متغیر | توضیح |
|---|---|
| `DATABASE_URL` | مسیر فایل SQLite (اجباری) |
| `AI_API_KEY` | کلید OpenAI-سازگار خودت (اختیاری — بدون آن از فول‌بک استفاده می‌شود) |
| `AI_BASE_URL` | آدرس سرویس AI (پیش‌فرض OpenAI) |
| `AI_MODEL` | نام مدل |
| `TELEGRAM_BOT_TOKEN` | توکن بات از @BotFather (فقط برای ربات) |
| `ADMIN_CHAT_ID` | آیدی عددی ادمین ربات |
| `MINIAPP_URL` | آدرس HTTPS مینی‌اپ برای دکمه ربات |

## 🌐 دیپلوی روی سرور (VPS)

پوشه `vps-deploy/` یک کیت کامل دیپلوی است:

```
vps-deploy/
├── deploy.sh               # نصب خودکار: Bun + build + systemd + فایروال چک
├── upload.py               # آپلود کل پروژه با SSH (paramiko)
├── apply-natal-update.sh   # آپدیت اتمی + مایگریشن DDL + ری‌استارت + هلث‌چک
├── bot.ts                  # سورس ربات استندالون
└── README-fa.md            # راهنمای گام‌به‌گام فارسی
```

ساختار پیشنهادی روی سرور: `/opt/warsentinel/{dashboard, bot, db, logs}` با دو سرویس systemd (`warsentinel-dashboard`, `warsentinel-bot`).

⚠️ **نکات امنیتی سرور:**
- بعد از دیپلوی حتماً `passwd` بزن (رمز موقت را عوض کن)
- `TELEGRAM_BOT_TOKEN` را در `/opt/warsentinel/bot/.env` با دسترسی `chmod 600` بگذار
- اگر پورت‌های 80/443 اشغال است (مثلاً x-ui/xray)، از پورت بالا مثل 9443 برای HTTPS استفاده کن
